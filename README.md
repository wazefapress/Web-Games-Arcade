# 🎮 مركز ألعاب أونلاين | Web Games Arcade

منصة ألعاب ويب متكاملة وخفيفة الوزن، تضم مجموعة مختارة من ألعاب المتصفح الكلاسيكية والحديثة جاهزة للعب فوراً بدون تحميل. تم تطوير المنصة لتكون سريعة، متجاوبة، وتعمل كـ تطبيق ويب تقدمي (PWA).

## 🌟 مميزات المشروع

* **مكتبة ألعاب متنوعة:** تجمع بين ألعاب الذكاء، الاستراتيجية، والألعاب الكلاسيكية الترفيهية.
* **تصميم متجاوبة (Responsive):** متوافقة تماماً مع كافة الشاشات (الهواتف الذكية، الأجهزة اللوحية، وأجهزة الكمبيوتر) بفضل إطار عمل Bootstrap 5.
* **دعم الـ PWA:** إمكانية تثبيت المنصة كتطبيق مستقل على الهاتف أو الحاسوب والعمل بكفاءة عالية.
* **سرعة فائقة:** تعتمد على تقنيات الويب الحديثة مع آليات تخزين مؤقت (Caching) عبر Service Worker.
* **مشاركة سهلة:** تتيح للمستخدمين مشاركة المنصة عبر ميزة المشاركة الأصلية للمتصفح.

## 🛠️ التقنيات المستخدمة

* **HTML5 / CSS3** (مع تخصيص متغيرات التصميم الحديثة CSS Variables).
* **JavaScript (ES6+)** لإدارة البيانات ديناميكياً وتفعيل PWA.
* **Bootstrap 5 (RTL)** لتنسيق الواجهات وتوزيع العناصر (Grid System).
* **FontAwesome** للأيقونات التعبيرية.
